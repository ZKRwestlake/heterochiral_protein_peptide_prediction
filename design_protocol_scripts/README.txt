These are the scripts we used to design heterochiral protein complexes like D1B/D1.
See https://www.nature.com/articles/s41422-024-01014-2 for details and Design_ptotocol_README.txt for how to use.
The design pipelines for other D-peptides are largely identical.
Differences mainly reside in hotspots selected or threshold values used for filtering, which are target-dependent.
